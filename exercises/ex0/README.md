# Getting Started

## Overview

Before diving into the exercises, you need to log in to both systems you will use throughout this workshop and orient yourself in the pre-populated environment.

**Duration:** 15 minutes

## Systems You Will Use

| System | Purpose |
|--------|---------|
| SAP AI Agent Hub (shared) | Central hub for AI agent discovery, assessment, and governance |
| Joule Studio (individual) | Your personal AI assistant environment where governance is enforced at runtime |

## Step 1 — Log In to SAP AI Agent Hub

1. Open your browser and navigate to the AI Agent Hub URL provided on your session card.
2. Sign in with the credentials provided.
3. You should see the **Agent Hub home screen** with a pre-populated agent inventory.

> **What you see:** The shared tenant has been pre-configured with a realistic set of agents representing a typical enterprise landscape — SAP-native agents, third-party integrations, and several "shadow" agents with incomplete or missing governance data.

## Step 2 — Log In to Joule Studio

1. Open a new browser tab and navigate to your individual Joule Studio URL (provided on your session card).
2. Sign in with your **SAP Universal ID**.
3. Confirm you can see the Joule Studio interface.

## Step 3 — Orient in AI Agent Hub

Take a few minutes to explore the interface before starting Exercise 1:

1. Locate the **Agent Inventory** view — this is your starting point.
2. Note the columns available: agent name, type, source environment, owner, risk classification, and verification status.
3. Observe that several agents have missing owners, unclassified risk, and no verification status — this is the shadow AI problem you are here to solve.
4. Find the **Governance** section in the navigation — you will use this in Exercise 2.

> **Note:** Do not make any changes yet. Exercises 1–6 will guide you through each action step by step.

## Summary

You are now logged in and oriented. In Exercise 1, you will use the agent inventory to understand the full scope of AI agent activity across the organization.
